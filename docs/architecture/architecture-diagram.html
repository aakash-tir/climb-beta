climb-beta Architecture

Phase 1: colour-blind hold segmentation, then a separate hold-colour step, then routes. One gym (Basecamp Climbing, Toronto).

Two-step design

  • • Detector never sees colour (hsv_h 0.5, enforced by config loader)
  • • Colour read from each mask after wall-referenced white balance
  • • Rules first (explainable); timm crop classifier if it beats them on val
  • • All colours + thresholds in configs/colours.yaml

Phase 1 exit criteria

  • • Hold recall ≥ 95% · mask mAP50 ≥ 0.85
  • • Colour ≥ 95% overall, ≥ 90% pink-vs-red, ≥ 90% chalked
  • • Named route within 1 hold on 9/10 test routes
  • • Phase 2 (animated beta) waits until all pass

Data rules

  • • Split by WALL; re-assign only places new walls
  • • SAM pseudo-masks never in a test split
  • • Basecamp photos gitignored, private HF dataset
  • • Model selection + test on Basecamp walls only
